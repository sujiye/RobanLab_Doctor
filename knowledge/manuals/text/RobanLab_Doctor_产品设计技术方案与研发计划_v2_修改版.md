## 摘  要

智能交互机器人实验课以 Roban 仿人机器人为教学平台，学生在机器人本机运行 Python 与 ROS 实验程

序。面对代码报错、节点异常或机器人动作失效，学生需要快速定位故障源并推进实验。为此，本项目设计了运

行在学生电脑端的 Web 应用软件 RobanLab Doctor，涵盖智能自检与软硬件联合诊断、课程功能包辅助调参以

及远程运动控制三大板块，并将研发进度细化至 S1 至 S14 共 14 个子模块以清晰界定核心与裁剪顺序。

系统以智能诊断 Agent 为核心引擎，融合远程 SSH 接入、实验前一键自检、确定性诊断流程树、本地课程

知识库与覆盖 22 个关节的标准运动用例。软件层面支持自然语言代码排障、差异确认修复与受控自动修复；软

硬件联合排查通过前端三维理想轨迹预演、现场环境安全确认与人工观察协同定因，疑似硬件或零位异常时输出

完整证据并提示上报老师换机。目前已有单机原型在真实 Roban 上跑通只读自检、规则归因与一次白名单修

复，后续按 M0 至 M5 里程碑推进完整闭环交付。

关键词：Roban 机器人；故障自检智能体；软硬件联合诊断；课程知识库；标准运动用例；受控修复

## 第一章  项目背景、原型基础与总体目标

### ▌ 1.1 教学场景与核心痛点

课程实验覆盖 Linux 远程开发、ROS 通信、关节运动控制、视觉伺服与动作编排等内容。学生程序部署于机

器人本机，经由 ROS 与厂家 BodyHub 中间层驱动全身 22 个舵机及视觉、音频与 IMU 外设。当程序报错或机

械臂无响应时，故障可能源自学生代码、机器人软件栈或底层硬件，现象高度趋同。相关排障知识分散在课件、

备份源码与助教经验中，亟需一套系统化工具将排障经验沉淀为可复用的自动化诊断流程。

### ▌ 1.2 设备现状与原型基础

实验室 Roban 机器人配备 20 个身体舵机与 2 个头部舵机，本机运行 Ubuntu 16.04、ROS 1 Kinetic 与

Python 2.7 及 3.5 环境，通过 BodyHub 对外提供状态查询、控制权管理、角度缓存、舵机位置直读、力矩锁定

与温度等服务接口。项目前期已完成单机原型验证，在真实设备上跑通只读自检、规则归因与一次白名单代码修

复，验证了电脑端经由 SSH 采集状态并闭环排障的技术路径。

### ▌ 1.3 项目总体目标

RobanLab Doctor 致力于打造安全、敏捷的课程实验辅助软件，助力学生快速明确下一步行动：

- 软件缺陷闭环修复：精准定位指定 Python 文件与运行环境问题，提供差异确认、自动备份、受控修复、复

测与一键回滚。

- 软硬件科学分流：按确定性流程树逐层取证，结合课程知识库、标准运动用例与人工现场判断定位故障；面

对疑似硬件或零位异常，输出清晰分析并提示上报教师换机。

- 实验效率提升：在保障核心自检闭环的基础上，为课程高频功能包提供快捷调参工具，并视进度补充轻量远

程运动控制。

### 2.3.2 纯软件通用 Agent 排障与受控修复

面对纯软件故障，自检 Agent 针对用户指定的远端 Python 文件与启动命令开展自然语言排障。系统自动分

析源码、报错堆栈、依赖与 ROS 通信日志，定位语法、导入、路径、话题消息及参数配置错误。修复交互默认

先展示修改差异 diff 与备份路径，经用户确认后自动备份、应用补丁并复测；同时支持用户在个人实验目录内开

启受控自动修复模式，并始终保留一键回滚入口。

### 2.3.3 软硬件联合流程树与课程知识库

当脚本运行正常但机器人动作异常时，Agent 结合现象沿确定性诊断流程树逐层排查：依次核验代码进程、

ROS 与 BodyHub 控制链路、控制权与参数，再读取舵机位置反馈与锁定状态。排查全程联动本地课程知识库，

为 Agent 提供 Roban 状态机约束、关节映射与历史案例参考，每条引用均附带原文出处与版本标识。

### 2.3.4 22 关节标准运动用例、三维轨迹预演与安全确认

系统内置覆盖 22 个关节的标准运动用例库，包含单轴往返、肩肘复合动作、参考姿态检查与腿部标准用

例，支持学生自主调用或由 Agent 联合排查时自动推荐。每次实机运行前，前端先以三维视图展示理想运动轨

迹、方向与幅度，供用户对照现场环境完成安全性评估。Agent 推荐的运动用例必须经用户环境确认后方可启

动。

腿部标准运动用例安全前置条件：腿部动作作为标准运动用例的正式组成部分，执行前须经严苛安全核验：界面强

提醒用户将机器人稳妥悬吊在合规吊挂装置上，逐项确认周围空间净空、线缆无拉扯且现场监护到位，保障机器人

绝不会摔倒，确认完成后方开放执行。

### 2.3.5 零位辅助检查与人机协同硬件分流

运动用例执行期间，系统同步对比理想轨迹与电机编码器反馈，并由用户通过观察表单填报实际位移、方

向、异响、下垂及参考姿态零位偏差。Agent 综合软件证据与现场判断完成归因：软件或参数问题转入受控修复

并复测；硬件或机械零位问题则汇总证据与可能原因分析，直接提示用户向指导教师汇报并换机继续实验。

### ▌ 2.4 次优先板块：课程功能包辅助调参

板，免去学生手改源码数组的繁琐。所有参数修改均经白名单范围校验，自动备份原文件并展示差异，支持一键
